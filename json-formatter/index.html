About this tool

Free, no sign-up. Formatting, validation and minifying all happen in your browser, so API responses, config files and tokens you paste here never leave your device. Part of techtuate, a growing collection of little tools that just work.

Output updates as you type. Format indents with two spaces; Minify strips every bit of whitespace. If the JSON is broken, the parser's message tells you what went wrong and roughly where.

questions people ask

Questions people ask

Is it safe to paste JSON into an online formatter?

With this tool, yes; all formatting and validation happen in your browser, so your JSON is never uploaded to a server.

How do I validate JSON online?

Paste your JSON and it is checked in-browser; invalid syntax is flagged so you can find the error without sending data anywhere.

What is the difference between formatting and minifying JSON?

Formatting (beautifying) adds indentation for readability; minifying strips whitespace to shrink the payload. This tool does both locally.
