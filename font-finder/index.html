Font finder

Paste or drop a screenshot and get the fonts in it: the family, a best-guess name, and real fonts you can actually use, closest Microsoft Office match first. Got a pesky PDF that was saved as an image and needs one small edit? Stop burning an hour matching the font by eye - paste it, and voila, you know what to type with. Same when you're editing an image and want the text you add to look like it was always there. It is a best guess, not a lie detector: it leads with the family and the closest matches rather than pretending to name every custom typeface exactly.

How to paste: copy any image or take a screenshot (Win+Shift+S on Windows, Cmd+Shift+4 then Control on Mac), then press Ctrl/Cmd + V here. Or drop / upload a file.

about this tool

About this tool

Free, no sign-up. Your screenshot is sent once to Google Gemini to read the fonts (this is a third-party call, and it is the exception here - most techtuate tools run fully in your browser). We do not store the image and there is no account. For each font it suggests real alternatives you can actually use, starting with the closest Microsoft Office / Windows font and then free downloadable ones (Google Fonts and other free foundries). Google Fonts preview live; Office and system fonts render in the preview only if you have them installed. Exact font identification is hard even for paid tools, so this leads with the family and closest equivalents rather than overclaiming. Part of techtuate, a growing collection of little tools that just work. Building a palette to match? Try the color palette extractor.

questions people ask

Questions people ask

How can I find out what font is in a screenshot?

Paste or upload the screenshot and the tool reads the text and identifies the likely font family, then suggests close matches. It identifies the family and nearest matches, not always the exact font.

Can I get a free Google Fonts version of a font?

Yes. For each identified font, the tool suggests the closest free Google Fonts equivalent alongside the closest Microsoft Office font, so you can use it in Docs or Word.

Is this font finder free and does it need an account?

It is free with no sign-up. The screenshot is sent once to a labeled AI service to identify the font and is not stored.
